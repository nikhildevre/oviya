# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅                 |

---

## Reporting a Vulnerability

If you discover a security vulnerability within Oviya, please **do not open a public issue**. Public disclosures can put users at risk before a patch is ready.

Instead, please report vulnerabilities privately:
* **Email:** Send details directly to the maintainer at `support@apurgroup.com` or via private message profile communication on GitHub.
* Include a description of the vulnerability, potential impact, and steps or proof-of-concept code to reproduce it.

You will receive an acknowledgment of your report within 48 hours, and updates as we work on a fix. Thank you for helping keep our users safe!
